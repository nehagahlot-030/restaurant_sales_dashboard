# Source Code – Restaurant Sales Dashboard

## 📌 Overview
This folder contains the Python source code for the Restaurant Sales Dashboard project.

The program uses Pandas and Matplotlib to analyze restaurant sales data and generate meaningful insights.

## 📂 Files

| File Name | Description |
|---|---|
| `restaurant_sales.py` | Main Python program for sales analysis |
| `restaurant_sales.csv` | Input dataset containing restaurant sales records |

## ⚙️ Functionalities

1. Read restaurant sales data using Pandas.
2. Calculate sales using Quantity × Price.
3. Handle missing and invalid data.
4. Group sales by category using GroupBy.
5. Calculate total sales by date.
6. Display top-selling items by quantity and revenue.
7. Generate charts using Matplotlib.

## 🛠️ Libraries Required

- Pandas
- Matplotlib
- CSV

## ▶️ How to Run

1. Open the source folder.
2. Install the required libraries:

   ```bash
   pip install pandas matplotlib
   ```

3. Run the Python file:

   ```bash
   python restaurant_sales.py
   ```

## 📊 Output

The program generates:
- Total restaurant sales.
- Category-wise sales.
- Daily sales analysis.
- Top-selling items by quantity.
- Top-selling items by revenue.
- Sales visualization charts.
