# Reports – Restaurant Sales Dashboard

## 📌 Overview
This folder contains the reports and visual outputs generated from the Restaurant Sales Dashboard project.

These reports help understand restaurant sales performance, category-wise revenue, daily sales trends, and top-performing menu items.

## 📂 Contents

This folder may include:

- Sales analysis reports
- Category-wise sales charts
- Daily sales charts
- Top-selling items reports
- Revenue analysis visualizations

## 📊 Report Details

### 1. Category-Wise Sales
Shows the total revenue generated by each restaurant food category, such as Starter, Main, and Dessert.

### 2. Daily Sales Analysis
Displays sales performance across different dates to identify daily trends.

### 3. Top Items by Quantity
Highlights the menu items sold in the highest quantities.

### 4. Top Items by Revenue
Shows the menu items generating the highest revenue.

## 🎯 Purpose

The reports are generated to:

- Analyze restaurant performance.
- Identify popular menu items.
- Understand revenue distribution.
- Support data-driven business decisions.

## 🛠️ Tools Used

- Python
- Pandas
- Matplotlib
